# Atelier 200 · 设计扩充

这次扩充采用统一规格 + 逐场景内容的方法，研究 Koco 的丰富场景、信息层次与主题组织，不复用其资产。

## 构图与内容

- 双环（orbit）：17 款设计规格。
- 分格（bento）：19 款设计规格。
- 时间轴（timeline）：12 款设计规格。
- 海报（poster）：16 款设计规格。
- 进度带（gauge）：15 款设计规格。
- 清单（list）：22 款设计规格。
- 细刻度（dial）：14 款设计规格。
- 票签（ticket）：22 款设计规格。
- 点阵（constellation）：13 款设计规格。
- 线形 / 声波（waveform）：12 款设计规格。
- 窗格（mosaic）：15 款设计规格。
- 编辑部（editorial）：23 款设计规格。

单个主数值承担视觉重心，最多三条辅助信息。低饱和背景、细边线与适度衬线替代高亮渐变和全粗标题。图片类使用原创程序化窗景示意，真实相册仍由原有 iOS 视图处理。图形中的数据均标记为预览；金融数值不作为投资建议或行情承诺。

六套色板为 mineral、ink、paper、rose、sky、dusk。主文字和辅助文字在两个渐变端点均接受 4.5:1 对比度校验；装饰线可以使用透明度，正文不依赖透明度表达。

## 三端实现与验收范围

- SwiftUI 新扩展采用 12 种构图；原有 45 款专项组件保留独立绘制与实时数据。学习组件使用真实词汇，票签 / 点阵 / 分栏因主题变化。
- Compose 使用 Canvas 绘制表盘、线形和原创窗景，字体缩放会提高预览高度。
- ArkUI 使用原生布局、Progress 与 Shape；复杂线形简化为节奏条，保持图形语义。鸿蒙工程仍需 DevEco Studio 编译与真机服务卡片检查。
- 离线校样用于全目录的内容、色板与构图检查，并非原生运行截图。小尺寸与大字体的原生最终效果须在设备上验收。
