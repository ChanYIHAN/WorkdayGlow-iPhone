# HarmonyOS platform override

- Use ArkTS, ArkUI semantic components and Form Kit cards; use system typography instead of bundled web fonts.
- Preserve the shared off-white/plum/mint/lavender/coral palette while respecting HarmonyOS safe areas and system card dimensions.
- Use 48vp minimum touch targets, lazy content where possible, explicit accessibility text and native routing/back behavior.
- Cards must support intentional refresh, router actions, transparent/dark backgrounds and platform-provided sizing.
- Keep animation purposeful and short; do not add continuous decorative motion to cards.
