# Android platform override

- Use Jetpack Compose, Material 3 semantic colors, Roboto/system typography and Dynamic Color where available.
- Preserve Ekhart Widgets' calm glass/Bento identity with tonal surfaces and restrained gradients; do not imitate iOS navigation chrome.
- All touch targets are at least 48dp, lists are lazy, state survives recomposition, and screen reader descriptions are explicit.
- Glance widgets use system corner radii, responsive/exact sizes, intentional loading/empty states and accurate picker previews.
- Motion uses native 150–300ms fades and container transitions and respects the system animation scale.
